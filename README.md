# CloudPlugins 问题回报

这里收云系列、星月系列插件的问题回报和功能建议。插件本身不开源，这个仓库只放 issue，没有源码。

文档：https://cloud.plugins.wiki
会员中心（下载、授权）：https://license.plugins.wiki

## 怎么回报

点上方的 Issues，再点 New issue，选「问题回报」或「功能建议」，照表单填就好。

回报问题时请尽量带上这几样，能少来回问好几次：

- 插件名称和版本（看 jar 文件名或后台启动时那行）
- 服务器核心和版本，例如 Paper 1.21.11、Leaf 1.21.11
- 有关系的其他插件，例如 CraftEngine、ItemsAdder、ModelEngine
- 从开服到出问题那段后台日志
- 怎么做会出现这个问题

发之前先搜一下有没有人回报过一样的问题，有的话直接在那里补充或点个赞就行，点赞多的会优先处理。

## 不要公开发的内容

刷物品、刷钱、绕过权限这类漏洞，请直接私聊作者，不要发在这里。公开出来等于教别人怎么用。

贴日志之前，请把授权码、服务器 IP、数据库账号密码遮掉。

## 处理进度

每个 issue 会贴上标签，看标签就知道进度：

- 待确认：还没看
- 需要更多信息：请照留言补资料，太久没回会关闭
- 已确认：重现了，排进修复
- 已修复：会写在哪个版本修好的，到会员中心下载新版
- 无法重现：照描述做不出来，有新线索可以再打开
- 重复：已经有人回报过，请到原本那个 issue 看
